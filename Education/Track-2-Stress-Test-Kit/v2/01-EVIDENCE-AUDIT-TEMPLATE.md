## Section 1 — The claim

**Reviewer prompt.** What should a teacher be able to conclude about a student who earns full marks on this task? Reconstruct it from the task text only. State it as one to three observable claims, each carried by a quoted task verb. Fewer claims than v1: the verification moment has to test them, and it has about six minutes.

**Fixed language.**

> Reading only the task as written, here is what we think a full-marks student has shown you they can do. Tell us where we are wrong — that correction is the most useful thing you can send back.

```
C1. A student who succeeds can [observable act]        — carried by: "[quoted task instruction]"
C2. ...
C3. ...
Not on this list, and why: [targets the task also touches that are procedural, assessed
   elsewhere, or lower-stakes here — phrased as a question: "we assume form conversion is
   assessed on the unit quiz; is this take-home the only place you see it?"]
```

**Rules.** Observable acts only ("attribute each coefficient to a feature of the situation"), never "understand." Quote the teacher's own verb. This section remains the experiment's accuracy measure (≥75% confirmed).

---

## Section 2 — The delegation test

**Reviewer prompt.** One question, answered plainly: given the assignment text, any provided materials, and anything the student carries out of the room — including checkpoints, cards, outlines, initialled predictions — can a current model produce all of the submitted evidence for C1–C3? Answer, then give the one-sentence reason.

**The carry-out rule (fixed).** Any artifact that leaves the room with the student is treated as available to a model, because it is. A checkpoint the student photographs is a prompt, not a proof. This is why the audit does not propose process artifacts.

**Fixed language — the answer.** One of two forms. No number, no bands.

> **Yes.** A current model can produce everything this task collects, because [the specific task feature — e.g. "the three situations are canonical and the prompt names every deliverable"].
>
> **No, because [the anchor].** Use only when some submitted evidence is produced under supervision or depends on something only the student has *and cannot carry out*. Name it. If you find yourself writing "because they'd have to explain it" — that is a yes.

**Fixed language — the disclaimer.** Print it every time.

> This is a professional judgment about the assignment as written, not a measurement of it. It says nothing about your students or your teaching, and nothing about whether anyone has used a tool on this task. It says what a tool *could* now do — a fact about the tools, not about your design.

```
Answer: [Yes / No, because ...]
Reason: [one sentence, task-specific]
Checked by: ["reviewer judgment only" / "assignment run through N current models on [date];
            output met the rubric at [level]"]
```

**Rule.** Expect "yes" nearly every time for anything sent home. Say so without drama. The audit's value is not in this section.

## Section 3 — The verification moment

**Reviewer prompt.** The smallest additional observation that gives the teacher independent evidence of C1–C3. It is a performance, not an artifact: produced in the room, under the teacher's eye, on a version of the problem the student has not seen, with the answer not available to be handed over. Write the actual item. Then answer the delegation test *on the moment itself*.

**Design rules (fixed).**

1. **Generated from the claim, not from the assignment.** Ask what a student who can do C1 would be able to do with a situation one step removed — a changed condition, an error to diagnose, a comparison, a prediction before calculation. Never "summarise what you submitted."
2. **Novel to the student.** A variant rule must exist so the item cannot be pre-prepared: which element changes, and how many versions the teacher holds. In math this is a parameter; in writing it is a new short source or a counterfactual.
3. **Supervised and bounded.** State the conditions exactly: where, how long, written or spoken, what is on the desk. Six minutes written to a whole class beats ninety seconds spoken to each student, on both cost and equity, whenever the claim allows it.
4. **Scorable in one line per claim.** For each claim, one sentence saying what a "yes, understands" answer contains. Sufficiency is stated before the item is run, not judged afterward.
5. **Coverage stated.** Everyone this cycle, or a named sample with a rule that reaches every student by [date]. Sampling is legitimate; silent sampling is not.
6. **One moment, not a menu.**

**Fixed language.**

```
The item (attach the full sheet; one variant shown here):
  [the actual text the student sees]

Variant rule: [what changes between versions; how many versions; how assigned]
Conditions: [in class / when in the cycle / N minutes / written or oral / what's allowed on the desk]
Coverage: [all students each cycle / sample of N per cycle, everyone by ___]

Sufficient evidence — a "yes" answer contains:
  C1: [one line]
  C2: [one line]
  C3: [one line]
  Threshold: [e.g. "two of three with a stated reason" — say why that is enough]

Delegation test on the moment itself:
  Could this be pre-prepared or handed over? [what a student would have to do in advance to
  fake it — and whether doing that would itself constitute learning the claim]
  Residual risk: [e.g. "a phone in a pocket during six supervised minutes" — name it]

Cost, honestly (our estimate — correct it after one run):
  To prepare:   [N] min once  ([variants × situations] keys, provided in the attachment)
  Class time:   [N] min per section
  To score:     ~[N] min per student, using the keys
  Per cycle, [your sections × students]:  +[N] class min, +[N] scoring min
```

## Section 4 — What the original task becomes, and the gradebook question

**Reviewer prompt.** The task is not redesigned. Say what it now is (practice, exploration, creation — with whatever tool policy the teacher chooses) and what it is not (the evidence for C1–C3). Then ask the one question the teacher may not be able to answer alone.

**Fixed language — the preservation statement (v2 form).**

> **What did not change.** Your task is unchanged: same situations, same deliverables, same tools, same week. What changed is which piece of evidence carries the claim. The task remains where students practise, explore and produce; the six minutes in Section 3 is where you see for yourself whether C1–C3 happened. Nothing about the task got harder or easier for a tool, and we are not asking you to police whether one was used.

**Fixed language — the gradebook question.**

> This audit assumes the verification moment can carry the grade weight the task used to carry, and the task can be checked for completion rather than graded in full. **Is that a decision you can make this semester without anyone's sign-off?** If not, tell us who owns it — a chair, a department vote, a district policy. That answer matters to us more than whether you like the audit.

**Rule.** Do not soften this. It is the adoption gate, and it is also the reason the paid product may sit with a department rather than a teacher.

## Section 5 — Why this and not a redesign (≤200 words, to a colleague)

**Reviewer prompt.** Plain prose to a peer. Tell the honest history in three moves: the task was well designed for a world without these tools; the first instinct (make the thinking visible with checkpoints) fails because the trail can be manufactured; so the evidence moved to a short moment in the room. Say what it costs and what it does not claim. End with the strongest argument against and the invitation to push back.

**Fixed opening and closing.**

> Opening: *Your task was well designed for a world without these tools; here is what changed underneath it.*
> Closing: *This is one professional's read of one assignment. If you ran the six minutes, tell us what it cost and whether it told you anything the project didn't — those two answers shape what we do next.*

## Reviewer's pre-return checklist

- [ ] Ownership line present, unchanged.
- [ ] Section 1: one to three observable claims, each quoting the task's verb; the "not on this list" line is phrased as a question.
- [ ] Section 2: Yes / No-because, one task-specific reason, "Checked by" filled, disclaimer printed.
- [ ] Section 3: the actual item text is present; variant rule, conditions, coverage, per-claim sufficiency lines, threshold with reason, the delegation test on the moment, residual risk named, full cost block.
- [ ] Section 3 mechanism is a supervised performance. If it is a card, a checkpoint, an outline, a draft, a log — it fails the carry-out rule. Rewrite.
- [ ] Section 4: preservation statement in v2 form; gradebook question asked verbatim.
- [ ] Section 5 ≤200 words, opens with the tone sentence, contains the honest history and the strongest argument against.
- [ ] Attachment: item sheet plus keys for every variant.
- [ ] Nowhere: "AI-proof," "cheat-proof," "vulnerable," "weak," "invalid," "detect," a score, a percentage, a rating.
- [ ] No student names, work, grades or roster fragments in what was received.
- [ ] Two pages + one attachment. Review minutes logged.

## Observed vs. modeled — this template

| Claim | Status |
|---|---|
| Information artifacts are consumable by a model once they leave the room | **Observed** in the v1 examples' own text; consistent with current literature on process evidence. |
| A supervised transfer item gives independent evidence of the claim | **Modeled.** It is the standard measurement position; Phase 0 tests whether it disagrees with the project grade often enough to matter. |
| Six minutes written beats ninety seconds oral on cost and equity | **Modeled**; the equity half follows from the plan's own blue-book evidence. |
| The gradebook is owned above the teacher in most departments | **Modeled** from experience; Phase 0's three chair conversations are the test. |
| All cost figures | **Modeled** until Phase 0 replaces them. |
