# Provenance of the synthetic cases

**None of these are the owner's own assessments.** Every file here was written or modified for Experiment A
and is labelled as such, because the difference matters to what the results can be read to mean.

| file | what it is | why it exists |
|---|---|---|
| `g11-calc-integration.md` | **Machine-authored.** A Grade 11–12 Honors Calculus techniques-of-integration quiz, written to be sound, supervised and closed-resource. | Extends grade contrast past Grade 10, and carries the paired-context test in the subject where the owner's own materials sit. **It is not a substitute for the owner's own Honors Precalculus/Calculus assessments**, which were not present in any connected folder and are the one pre-registered cell this run cannot fill. A machine-authored assessment cannot test "does it leave a strong *expert-authored* assessment alone", because the same family of model wrote it. |
| `g5-P1-no-diagnose.md` | Gold `g5-math-fractions` with **item 9 deleted**, teacher note retained. | Planted no-item gap: the teacher states a diagnostic claim the assessment no longer reaches. |
| `g5-P2-selected-response.md` | Gold `g5-math-fractions` with **Part A converted to bare multiple choice**, no work shown. | Planted narrowing: recognition survives, strategy execution does not, and a guess rate appears. |
| `g8sci-P3-no-item6.md` | Gold `g8-sci-ramp-data` with **item 6 deleted**. | Planted no-item gap in a second subject — item 6 is the one the gold record names as "the difficult part". |
| — (no file) | Gold `g10-ss-gilded-age`, **text unchanged**, run with a teacher note scoping sourcing out. | The false-positive test: something the assessment touches but the teacher assesses elsewhere must be scoped out, not reported as a gap. Changing the text would have made this a different test. |
| — (no file) | Gold `g5-math-fractions/fixtures/visible-valid-excessive-burden.md` | The over-verified case. Already in the repo, written by the owner's harness. Not copied here; referenced in place. |
