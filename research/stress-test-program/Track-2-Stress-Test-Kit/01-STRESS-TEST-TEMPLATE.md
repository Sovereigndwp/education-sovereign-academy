# Assessment Stress Test — the 2-page template

**Status:** draft for Dalia's approval · 2026-09-04 · nothing sent, no software.
**Source of truth:** ASSESSMENT-STRESS-TEST-PLAN.html §5 (six sections), §9 (ethics), §11 (the teacher-minutes risk).

This is the exact artifact a teacher receives. Everything in `[brackets]` is a prompt for the reviewer (Dalia) to fill. Everything not in brackets is fixed language and should be used verbatim unless Dalia edits the template itself. Two worked examples follow in files 02 and 03.

---

## Page-length discipline

Two pages, printed, 11-pt. If it runs to three, cut Section 6 first, then Section 2's per-target detail. The teacher will read this between classes; a three-page audit is an unread audit.

## Section 1 — What this assignment is trying to measure

**Reviewer prompt.** Reconstruct the intended learning from the task itself — not from the standard the teacher may have listed, and not from what we think the unit *should* teach. State each target as an observable claim about what a student who succeeds can do, and quote the task verb that carries it. Three to six targets. If a target looks like filler, say so gently and ask.

**Fixed language.**

> Reading only the task as written, here is what we think it asks a student to demonstrate. Please tell us where we are wrong — that correction is the most useful thing you can send back.

```
T1. [observable claim]            — carried by: "[quoted task verb / instruction]"
T2. [observable claim]            — carried by: "[quoted]"
T3. ...
Where we're unsure: [one line, e.g. "Part 5 may be a communication target or may be filler — which?"]
```

**Rules.**
- Observable claims only: "distinguish long-term from immediate causes," "attribute each coefficient to a feature of the situation." Never "understand," "appreciate," "be familiar with."
- Quote the teacher's own words for the verb. This is what lets them say *yes, that's what I meant.*
- This section is the accuracy measurement for the whole experiment (§7, "Our accuracy"; §8, ≥75% confirmed). Write it to be confirmable or correctable, not admired.

## Section 2 — Where a current model can substitute for the evidence

**Reviewer prompt.** Target by target: what can a current, freely available model produce from the assignment text alone, without the student doing the thinking? Be specific to *this* task — name the instruction, name what comes out. Then give the one-band judgment for the assignment as a whole.

**Fixed language — the three bands.** Use exactly one of these sentences, then attach the reason. These are the only three options; there is no fourth band and no number.

| Band | Exact sentence | Use when |
|---|---|---|
| 1 | **"A current model can produce the whole artifact."** | Every target's evidence is producible from the prompt and any provided materials. Nothing in the submission depends on something only the student has. |
| 2 | **"A current model can produce most of it, but not [named step]."** | One or more targets depend on a specific step the model cannot perform for the student — name it. |
| 3 | **"A current model can assist, but the evidence of thinking survives because [reason]."** | The task already anchors the evidence to something the student did or holds (in-class data, a prior prediction, a chosen artifact, a live exchange). Name the anchor. |

**Fixed language — the disclaimer.** Print it every time, immediately under the band.

> This is a professional judgment about the assignment as written, not a measurement of it. It says nothing about your students, your teaching, or whether anyone has used a tool on this task. It says what a tool *could* now do — which is a fact about the tools, not about your design.

```
Per target:
T1 — [what a model produces for this target from the text alone; specific]
T2 — [ ]
...
Judgment: [Band sentence, verbatim] — because [the specific task element that drives it].
Checked by: [ "reviewer judgment only" / "assignment text run through N current models on [date]; output satisfied the rubric at [level]" ]
```

**Rules.**
- The band cites the task element that drives it. "Because it's an essay" is not a reason; "because the six documents are in the packet and the prompt names the position to argue" is.
- Say how the judgment was made. "Reviewer judgment only" is acceptable and must be labelled as such. Running the text through a model is better and takes ten minutes; the Phase-0 dry run should establish whether Dalia does this every time.
- Tone: this section is where the audit can go wrong. Never "this assignment is vulnerable / weak / easy to cheat." Always "here is what changed underneath it."

## Section 3 — What thinking must remain visible

**Reviewer prompt.** Name the cognitive-demand invariant: the reasoning that, if it disappears from the evidence, means the assessment no longer measures the objective in Section 1. Usually one or two of the targets, not all of them. Say which targets are procedural and are (probably) assessed elsewhere — and ask.

**Fixed language.**

> If the redesign preserves nothing else, it must keep this visible:

```
The invariant: [one or two sentences naming the specific reasoning — e.g. "the student's own attribution of each coefficient to a feature of the situation, and their reading of the vertex as a statement about that situation"]
Why this and not the rest: [which targets are procedural / assessed elsewhere / lower-stakes here — with "please correct us" if it's an assumption]
```

## Section 4 — One redesigned version

**Reviewer prompt.** Write the actual replacement task text, as the teacher would hand it out. Same objective. Same cognitive-demand band. Minimal edits to the original — the teacher should recognise their assignment. Show the rubric if the original had one. Then the preservation statement.

**Rules.**
- One redesign, not options. Options are a workshop.
- Change as little as possible. The best redesign is the original with one structural addition and one subtraction.
- Every minute the verification mechanism adds must be paid for by something removed. Say what was removed and why removing it does not touch the invariant.
- Never lower the demand band to make substitution harder ("make them do it on paper in 20 minutes"). That is the free substitute we are competing with, and it is worse pedagogy.

**Fixed language — the preservation statement.** Every audit carries this, in this form:

> **What did not change.** The learning objective is the same: [restate T-targets in one line]. The cognitive demand is the same band: a student who could earn full marks on the original has to do the same reasoning here, [plus/minus nothing / plus one act of comparison they were already implicitly doing]. The topic, the situations offered, the tools allowed, and the point total are unchanged. You can check this claim yourself: [the one-line audit the teacher can run — e.g. "line up the original rubric rows against the new ones; every row maps to one"].

## Section 5 — One verification mechanism (and what it costs you)

**Reviewer prompt.** Choose exactly one of four, fitted to the teacher's constraints as we understand them (class size, whether they see students daily, paper vs. LMS). Name the mechanism, state how it is run, state how it is reviewed, state the cost in teacher-minutes honestly.

**The four mechanisms — pick one, not a menu.**

| Mechanism | What it is | Typical cost |
|---|---|---|
| Prediction checkpoint | Before any work, in class, the student commits a short prediction (outcome, direction, which quantity matters). Teacher initials it. Final work must reconcile against it. | 3–7 class min; ~0–1 review min per student |
| Selected-evidence step | In class, the student chooses and briefly warrants the specific evidence/data/case they will build on. Teacher initials. Final work must use it. | 8–12 class min; ~1 review min per student |
| Worked-reasoning artifact | A bounded, in-class or handwritten intermediate (a plan, a first attempt, a labelled sketch) that the final product must visibly descend from. | 10–15 class min; 1–2 review min per student |
| Defense questions | 2–3 questions generated from *this* task, asked of a sample of students or of everyone in 90 seconds each, at the moment of submission. | 0 class min to set; 1.5–3 min per student asked |

**Fixed language — the cost line.** This is required. It is the direct test of the plan's biggest known risk (§11) and the teacher will trust the audit more for seeing it.

```
Mechanism: [name]
How it runs: [two or three sentences — the teacher's actual moves]
How it is reviewed: [what the teacher looks at, and for how long]

Cost, honestly (our estimate — please correct it after you run it once):
  Class time:   original [N] min per section  →  redesign [N] min per section
  Review time:  original ~[N] min per student →  redesign ~[N] min per student
  Where the minutes came from: [what was removed to pay for it]
  Net for [your sections × students]: [+/− N minutes per assignment cycle]
```

**Rules.**
- Estimate, label as estimate, ask for the real number. The follow-up question after use is always: "How long did it take you to run and review, compared with the original?" Log the answer verbatim (tracking sheet, `minutes_comparison_verbatim`).
- If the honest net is more than +10% review time, say so and say why we still think it is worth it — or choose a cheaper mechanism.

## Section 6 — Why this is stronger (≤200 words, to a colleague)

**Reviewer prompt.** Plain professional prose, addressed to a peer, no jargon, no "AI-proof," no scolding. Say what the world changed, what the redesign anchors the evidence to, what it costs, and what it does not claim. End with the strongest argument against the redesign, in one sentence, and the invitation to push back.

**Fixed language — the opening and closing sentences.** Use these or close variants.

> Opening: *Your task was well designed for a world without these tools; here is what changed underneath it.*
> Closing: *This is one professional's read of one assignment. If you used it, tell us what it cost you to run — that answer shapes what we do next.*
