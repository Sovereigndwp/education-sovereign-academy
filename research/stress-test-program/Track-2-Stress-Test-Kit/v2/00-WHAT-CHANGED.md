# v2 — what changed and why

**Status:** draft · 2026-09-04 · supersedes v1 files 01, 02 and the Phase 0 design in the plan. v1 is kept, unedited, because it is the record of a hypothesis that was falsified before it was sold.

## The finding that forced this

Every verification mechanism that exists as information becomes context for the next AI call. The v1 history example admitted it in one clause ("a student can photograph the card for a model") and then built the redesign on the card anyway. Of the plan's four mechanisms, three (prediction checkpoint, selected-evidence step, worked-reasoning artifact) are information artifacts and fail this test. Only one survives: a performance produced under conditions where the answer cannot be handed over.

So the v1 premise — "redesign the assignment so student thinking remains visible" — is too optimistic. The assignment is no longer the unit to fix.

## The new organizing question

> If anything sent home can come back through AI, what is the smallest piece of evidence a teacher needs to see for herself before she can reasonably say: yes, this student understands?

Not minimum evidence of authorship. Not AI-resistant assignments. Minimum sufficient evidence of learning.

## Locked decisions — status after v2

1. *No numerical score; three-band qualitative judgment.* **Kept in spirit, changed in form.** For take-home evidence the answer is binary and almost always "yes, all of it," so three bands add ceremony without information. The professional-judgment disclaimer stays. The judgment that still needs care is whether the *verification moment itself* can be delegated — that is where the qualitative reasoning now lives. Reopened with reason; Dalia to confirm.
2. *Assignments only, never student work.* **Unchanged.** Note: the verification moment produces student work in the teacher's classroom; it never comes to us. Only the teacher's minutes and counts do.
3. *Audit belongs to the teacher.* **Unchanged.**
4. *Secondary math wedge + ELA/history contrast cell.* **Confirmed, and strengthened** — reversing Track 1's advice. Verification is only cheap where variants are cheap. In math a parameter change produces a new supervised item in seconds and is scorable in a minute; in history a transfer question needs a human to listen to each answer. The contrast cell now documents that writing-heavy subjects need a different machine, not whether math has pain.
5. *Service first, software later.* **Unchanged**, but the horizon moved: this is a research program before it is a service. The department sprint is twelve months out, not the next artifact.
6. *Free deliverable is a real value exchange.* **Unchanged.** The deliverable is now a ready-to-run verification item with keys, which is more immediately usable than a redesigned assignment.

## What is paused

All outreach (v1 file 05). The submission form (04) and tracking schema (06) are still valid but need the fields in `03-PHASE-0-REVISED.md` added. The department sprint (07) is shelved until Phase 0 reports.

## What is not yet solved, stated plainly

The verification moment is, from a distance, a quiz. What makes this more than 1995 is the sufficiency claim: *this* item, tied to *this* claim, novel rather than recall, sampled *this* way, is enough — and here is the confidence it earns. Phase 0 establishes cost and an existence proof of the evidence gap. It does not yet establish sufficiency. That is Phase 1's job and it is the actual research question.
